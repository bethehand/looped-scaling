## 他们匹配了什么
- 三类比较，匹配量各不相同：
  1. 训练 scaling law（Sec. 5.2, Appendix O(1)）：**固定参数量（140M 或 370M）+ 固定训练 FLOP 预算**，在 μ_rec 与 token 之间权衡（"increasing μ_rec reduces the token budget proportionally"）。"Fixed-Depth" 基线是 μ_rec=1 的同参数 Parcae，在同一 FLOP 预算下用更多 token（Table 6/16）。
  2. 测试时 scaling（Sec. 5.3, Appendix O(2)）：**固定参数 + 固定数据 11.2B tokens**，μ_rec ∈ {2,4,6,8,10,12}，评测 T = 1…24。
  3. 端到端对比（Sec. 5.1）：vs RDM（Huginn）与 vs Transformer 均为 **参数匹配 + 数据匹配**（"parameter- and data-matched"），**不匹配训练 FLOP，也不匹配推理 FLOP**。论文未给出倍数；按 Appendix D 的公式与 Table 18 的 P/R/C 三等分自行估算（本笔记推算，非原文数字）：μ_rec=8、μ_bwd=4 时训练 ≈ (6·2/3 + (2·4 + 6·4)/3)·N ≈ 14.7N vs 6N，约 2.4×；推理前向 ≈ (2/3 + 8/3)·2N ≈ 6.7N vs 2N，约 3.3×。
- 参数定义（Appendix D）："we exclude embedding parameters from N̂, however, we do include unembedding parameters in N̂ similar to Karpathy [42]"（注意 Table 18 写 Tied Embeddings: Yes）。Parcae 相对 Transformer 多出 0.35%–0.83% 参数（Table 19：140M +1,181,952；370M +2,100,224；770M +3,280,640；1.3B +4,723,200；总数 144,323,136 / 388,003,328 / 776,655,680 / 1,338,591,744 vs Transformer 143,141,184 / 385,903,104 / 773,375,040 / 1,333,868,544）。
- FLOP 公式（Appendix D）：有效参数 N̂（"for a model that is a single layer with N parameters, if it is looped ten times, then it has an effective parameterization of N̂ = 10N"）；分为不反传的 N̂₁ 与反传的 N̂₂，**C = (2·N̂₁ + 6·N̂₂)·D**，"which further matches the setup of McLeish et al. [49]"；另加 attention FLOP 估计（"following Chowdhery et al. [13], Karpathy [42]"，未给显式公式）。未说明注入模块（A, B, C, Δ）的 FLOP 如何计入。

## 模型与训练设定
- 核心机制（Sec. 4.1, Eq. 3, Algorithm 1）：e = LN(P(s))；h_{t+1} = Ā·h_t + B̄·e + R̄(h_t, e)；p = C(C·h_T)。A := Diag(−exp(log_A))，log_A ∈ R^{d_h} 可学习（负对角保证连续系统特征值为负）；离散化 Ā = exp(Δ⊙A)（ZOH），B̄ = Δ·B（Euler），Δ ∈ R^{d_h} 可学习；B 不加约束；C 为 readout 投影（解耦 R 与 C 的维度）。这相当于循环内对残差状态做**可学习逐维衰减，保证 ρ(Ā) < 1**，是本文意义上的"残差缩放"。Table 1 对照：Addition 注入 Ā = I（marginally stable）；Concatenation 注入 Ā ∈ R^{d_h×d_h} 无约束（unstable）。
- 初始状态：h_0 ~ N(0, σ²I)（Sec. 2.1 / Eq. 3；Table 17/18 写 "State Init.: like-init [27]"），**σ 数值全文未给出**。
- 归一化：Pre-Norm RMSNorm；不用 Huginn 的 Pre+Post 残差归一化（"residual normalization is unnecessary when stability is properly controlled"，Sec. 2.1）；额外在 prelude 输出加 LN（Appendix J，为修复 1.3B 在 ∼150k 步后的 loss spike）。
- 两套架构：
  - RDM 对照（Table 17）：Parcae-100M 114,242,560 参数，P/R/C 层数 1/1/1，d_model 1,024，d_int 3,520，μ_rec = 16，backprop depth 8；Parcae-350M 378,558,464（RDM-350M 382,765,056），1/2/1，2,048，7,040，μ_rec = 8，backprop depth 4；SwiGLU；RoPE θ = 50,000；RMSNorm；init N(0, 2/(5d))（Takase et al.）；vocab 65,536；tied embeddings；Poisson 采样。
  - Transformer 对照 + 全部 scaling 实验（Table 18，nanochat 风格）：Small 140M：Transformer 6 层 → Parcae P/R/C = 2/2/2，d_model 768，d_int 3,072，6 heads；Medium 370M：12 层 → 4/4/4，1,024，4,096，8 heads；Large 770M：18 → 6/6/6，1,280，5,120，10 heads；XLarge 1.3B：24 → 8/8/8，1,536，6,144，12 heads；head dim 128；QK-Norm；ReLU² MLP；gated value embeddings（alternating layers）；RoPE θ = 50,000；vocab 32,768（自训 BPE，Appendix R）；context 2,048；无 bias；init "Scaled-zero [74, 42]"；tied embeddings；注入 Diagonal；μ_rec = 8；backprop depth 4；采样 "Poisson (truncated, per-sequence)"。即 **循环块 = 中间三分之一层**，prelude/coda 各占三分之一（"we loop the middle third layers"，Sec. 4.1）。
- 循环次数采样：训练时 T **按序列（per-sequence）** 从 Λ = Poisson(均值 μ_rec) 采样（Algorithm 2：取 batch 内 T_max，较短的序列先 "no state update"，wall-clock 开销 +1.8%）。Algorithm 4：T ~ Λ(μ_rec)，n = max(T − μ_bwd, 0) 步无梯度，k = min(T, μ_bwd) 步有梯度；**Λ 只由 μ_rec 参数化**，不像 Geiping（Algorithm 3 / Eq. 5：τ ~ N(log(μ_rec − μ_bwd) − σ²/2, σ)，σ = 1/2，n ~ P(e^τ) + 1，k = μ_bwd）那样把分布截断压缩。"truncated Poisson" 的截断方式未说明。
- 反传截断：**全部主实验都截断**，μ_bwd = ⌈μ_rec/2⌉（Eq. 6, Appendix I）；主实验 μ_rec = 8 → μ_bwd = 4。full BPTT 只出现在 Appendix H 的 100M / 10B-token 消融基线（Figure 14，数值仅图中可读）。
- 优化（Appendix Q.2, Table 20/21，nanochat 设置）：AdamW（wte、lm_head、RMSNorm、ve_gate、所有 1D 参数；Parcae 的 A、Δ、B、C 也归 AdamW）+ Muon（attention 与 MLP 矩阵）；AdamW LR 8e−3（140M/370M）、6e−3（770M/1.3B），β = (0.8, 0.95)，WD 0.0，ε = 1e−10；Muon LR 8e−3，momentum 0.95，WD 0.2（线性衰减到 0），5 步 polar-express 正交化，factored variance reduction，cautious weight decay；LR 调度 **"Fixed (0% warmup, 50% cooldown)"**；grad clip 1.0；bf16-mixed；batch 256 序列 × 2,048 = 524,288 tokens；tokens 11.2B / 29.6B / 61.6B / 104B。LR 只在 Transformer 上扫（small/medium：AdamW 13 个值 {3e−4 … 2e−2} × Muon 9 个值 {3e−4 … 2e−2}，1:20 param:token，两者最优均 8e−3；large/xlarge：AdamW {2e−3, 3e−3, 4e−3, 6e−3, 8e−3}、Muon 固定 8e−3，1:7，最优 6e−3）；**Parcae 不扫 LR，直接沿用**。
- RDM 设置（Appendix Q.1）：warm-up 与 cool-down 各 4096 步 + 常数 LR；Adam β1 = 0.9, β2 = 0.95，update clipping，去掉 ε，grad clip 1；LR 扫 {2e−4, 4e−4, 6e−4, 8e−4, 1e−3}，约 10:1 token:param。原文同时写 "η = 4×10⁻³ for 100M models and η = 2×10⁻³ for 350M models" 与 "4e−4 for 100M and 2e−4 for 350M"，前者超出扫描范围，疑为笔误。数据用 Huginn 数据集与 tokenizer。
- 数据：FineWeb-Edu；BOS-aligned dataloader + BestFit-Crop packing；自训 GPT-4 风格 byte-level BPE，vocab 32,768，2B 字符训练，4.72 / 4.65 bytes/token（train / val，Table 22）。
- 规模网格：isoFLOP：140M × μ_rec ∈ {2,4,6,8,10,12} × C ∈ {1,2,4,8,16,64}×10¹⁸ = 36 runs；370M × 同 μ_rec × {32,64,128}×10¹⁸ = 18 runs；另加各预算的 μ_rec = 1 基线（Appendix O(1)）。测试时：140M/370M × μ_rec ∈ {2,…,12}，11.2B tokens（O(2)）。Unified：isoFLOP 模型在 T ∈ {1,2,4,6,8,10,12,16,20,24} 评测，每个尺寸约 540 点（O(3)）。消融：100M / 10B tokens，μ_rec = μ_bwd = 8（Appendix H）；μ_rec ∈ {4,8,14,20,26,32}、μ_bwd = 4 固定、10B tokens（Table 9）；μ_rec = 20 固定、μ_bwd ∈ {4,6,8,10,12}、8.5B tokens（Table 10）。
- 种子：**训练种子未提**；下游评测 3 个种子（因 h_0 随机与 few-shot 样本变化，Appendix M）。

## 函数形式与拟合方法
- 训练律（Sec. 5.2 写作 L̂(μ_rec, D) = E + X·N(μ_rec)^−x + Y·D^−y；Appendix K Eq. 7 写作 L̂_train(μ_rec, D) = E + A·N(μ_rec)^−a + B·D^−b）：E 不可约损失；N(μ_rec) = "the effective parameter count of the model if you were to unroll all loops into real parameters"（原文如此，**未给显式公式**；iso-depth 论文 Appendix A 将其解读为 N_eff = μ_rec·N "prelude and coda included"，与原文措辞"unroll all loops"更像 N_P + μ_rec·N_R + N_C 不一致，需注意）；D 训练 token；A/X, a/x, B/Y, b/y 拟合参数。**没有 φ 一类的自由指数**：有效参数对 μ_rec 线性（相当于固定 φ = 1），次线性收益全部由指数 a 吸收；又因参数量固定、只有 μ_rec 变化，a 与 "φ" 不可分离。
- 拟合（Appendix K）：Huber loss on log loss，L-BFGS，500 次随机重启，每次最多 10,000 迭代，取 Huber 最小者；δ 未说明（测试时曲线处写 δ = 1e−3）；无 box 约束说明；**无置信区间**；未提排除点；**140M 与 370M 分别拟合**。
- Table 11：Small (140M)：E = 2.662, A = 522733.307, a = 0.771, B = 25420.102, b = 0.525, Huber 0.44×10⁻⁴；Medium (370M)：E = 2.439, A = 832134.346, a = 0.775, B = 6386.865, b = 0.448, Huber 0.01×10⁻⁴。预测 Sec. 5.1 held-out 模型的验证损失误差 1.3%（140M）、0.8%（370M）。
- 抛物线拟合（Sec. 5.2, Figure 5）：每个 isoFLOP 预算对 μ_rec 拟合二次曲线取最小值；正文 γ_μ ≈ 0.40、γ_D ≈ 0.78；Figure 5 图例（**仅图中可读**）：μ*_rec ∝ C^0.40（140M）、C^0.38（370M）；D* ∝ C^0.77（140M）、C^0.78（370M）。各预算 μ*_rec（Table 6）：140M：1e18→2，2e18→2，4e18→4，8e18→6，16e18→8，64e18→10；370M：32e18→4，64e18→6，128e18→6。

## 主要结论
- φ 或等价指标：**无 φ**。可类比的量是训练律指数 a = 0.771（140M）/ 0.775（370M）（Table 11）与 compute-optimal 幂律 μ*_rec ∝ C^0.40/0.38、D* ∝ C^0.77/0.78（Figure 5）。结论 "looping and data should be increased in tandem, given a fixed FLOP budget"（Abstract）。
- 稳定性：Pre-Norm RDM 在 LR ≥ 4e−4 发散，Res.-Norm RDM 在 LR ≥ 6e−4 发散，Parcae 在 {2e−4, …, 1e−3} 全部收敛（Table 2）；发散的 run 学到 ρ(Ā) ≥ 1（Figure 3）。
- 端到端（参数 + 数据匹配）：vs RDM（Table 3）：验证 PPL 100M 14.23 → 13.59，350M 10.76 → 10.09（正文 "up to 6.2%"，摘要 "6.3%"）；WikiText 63.27 → 60.33、41.31 → 37.53（"9.1%"）；下游平均 45.03 → 46.83、49.45 → 50.12。vs Transformer（Table 5）：Val PPL 21.48 → 19.06（140M）、15.79 → 14.49（370M）、13.08 → 12.49（770M）、11.95 → 11.42（1.3B）（正文称 "4.3–9.2%"；按表中数字自算 140M 为 11.3%，与正文范围不符）；Core 13.00 → 14.04、17.46 → 20.00、22.42 → 25.07、25.45 → 28.44；Core-Ext 8.80 → 9.67、11.71 → 12.75、14.20 → 15.19、15.90 → 17.08；770M Parcae Core 25.07 ≈ 1.3B Transformer 25.45。
- 消融（Table 4，140M retrofit）：RDM 发散；+ 约束 Ā：Val loss T=1/4/8 = 8.99/3.15/2.97；+ per-seq 采样：3.38/3.01/2.98；+ prelude norm：3.28/2.97/2.95。
- 截断反传的影响：Table 10（μ_rec = 20 固定，8.5B tokens）：μ_bwd 4/6/8/10/12 → Val loss 2.500/2.490/2.480/2.479/2.474（T = 16, 64 随 μ_bwd 单调改善；10 → 12 增益极小）。Table 9（μ_bwd = 4 固定，10B tokens，T = μ_rec）：μ_rec 4/8/14/20/26/32 → 2.477/2.453/2.456/2.457/2.458/2.458，μ_rec > 8 反而更差："the capabilities of looped models utilizing deeper recurrences are heavily coupled with μ_bwd"。Appendix H：Algorithm 4 使 T = 4 的验证损失显著优于 Geiping 采样，T = 8 三者几乎相同（Figure 14，数值仅图中）。
- 循环位置：固定 "middle third"，未变化；Discussion 列为未来工作。
- 训练 FLOP 匹配 vs 参数匹配：isoFLOP（参数固定）下最优 μ_rec > 1 比 μ_rec = 1 的同参数基线损失更低、高预算下 Core 高 1.2–2.0 分（Sec. 5.2, Table 6：140M 64e18 时 16.2/11.0 vs 15.0/9.5；但低预算 1e18、2e18 时 fixed-depth 反而更好：7.9/6.1 vs 7.6/5.7、10.5/6.4 vs 9.0/6.2；370M 32e18 时 16.8/11.2 vs 15.2/10.1）。**没有与更大参数量稠密模型的 FLOP 匹配比较**。
- 测试时循环外推：饱和指数律；增益在 T ≈ μ_rec 附近平台化（"training depth determines the test-time scaling ceiling"，Sec. 5.3）；衰减率 ∝ 1/μ_rec；per-seq 采样大幅改善低 T（Table 8：100M T=1 PPL 300.32 → 70.47，T=4 36.75 → 17.15，T=8 16.65 → 14.08，T=16 13.81 → 13.59；350M T=1 167.61 → 17.92，T=4 12.80 → 10.49，T=8 10.40 → 10.09，T=16 10.24 → 10.11）。
- 下游：有信号——参数 + 数据匹配下 Core/Core-Ext 提升 2.99/1.18 分；isoFLOP 高预算下提升 1.2–2.0 分；相对"下一个更大 Transformer"的参数效率 23.3–87.5%（Core）、29.9–58.2%（Core-Ext）。

## 失败模式与警告
- 拼接注入（Huginn 式 W[h; e]）的 Ā = W₁ 无约束 → 残差状态爆炸与 loss spike；需要敏感的 LR 与残差归一化（Sec. 3, Table 2, Figure 2/3）。
- 1.3B 在约 150k 步后（正文另一处写 "after 170k steps"）出现 state explosion 与 loss spike，根源是 prelude 中单层导致残差范数爆炸并经注入放大（Figure 21/22）；修复：prelude 输出加 LN（Appendix J）。C 的谱范数持续增长但实际放大比小（Figure 18/19）。
- per-micro-batch 深度采样导致 loss spike 与最后一次循环残差跳变过大（Figure 10/11）；per-sequence 采样消除之。
- Geiping 的采样（n ~ Λ(μ_rec − μ_bwd)，k = μ_bwd 固定）使训练循环分布被截断压缩，损害对更少/更多 T 的泛化（Appendix H）。
- 固定 μ_bwd 时增大 μ_rec 无益甚至有害（Table 9）；μ_bwd 决定深循环能力（Table 10）。
- 评测：T = 1 时 PPL 极差（Table 8），随机 h_0 使评测有方差，需要多种子；Parcae 无 LR 扫描（"We stipulate that Parcae models would likely perform better with stronger hyperparameter tuning"）。
- 低 FLOP 预算下 looping 不占优（Table 6 的 1e18 / 2e18 / 32e18 行）。

## 对我们实验的直接启示
**应该照搬**
- 稳定性配方：h_{t+1} = Ā·h_t + B̄·e + R̄，A = Diag(−exp(log_A))，ZOH 离散化，Δ 可学习；prelude 输出 LN；注入参数（A, Δ, B, C）放在 AdamW 组。这是在 20M–160M 上用较高 LR 也能稳定的廉价方案。
- 循环采样（若采样 T）：Algorithm 4（T ~ Poisson(μ_rec)，k = min(T, μ_bwd)，n = max(T − μ_bwd, 0)）+ per-sequence 采样；截断默认 μ_bwd = ⌈μ_rec/2⌉。
- 训练配方数值（Table 21）：batch 524,288 tokens、seq 2,048、AdamW LR 8e−3 与 Muon LR 8e−3（140M/370M）、β = (0.8, 0.95)、Muon WD 0.2 线性衰减到 0、grad clip 1.0、无 warmup、50% 冷却；vocab 32,768。
- 拟合流程：Huber-on-log + L-BFGS + 500 起点；测试时曲线用带 floor 的指数 L_∞ + Z·e^{−zT}，不用幂律；把 L(T = μ_rec) 当作训练律 floor 的校验（误差 < 0.6%）。
- FLOP 记账 C = (2N̂₁ + 6N̂₂)·D，与 iso-depth Eq. (6) 一致，可作为截断反传的通用公式。

**应该避免或改进**
- 不要把 Table 5 的"参数 + 数据匹配"结果当作 FLOP 匹配证据；我们的主比较必须是训练 FLOP 匹配。
- 他们的训练律把有效参数写成 μ_rec 的线性函数（隐含 φ = 1），且参数量固定，所以指数 a 与 φ 混淆；我们要同时变化唯一参数量 N 与 r，才能把 φ 从 α 中分离。
- 不要只用截断反传：他们没有 full-BPTT 的 scaling 数据（仅 Appendix H 单点消融）；我们要把 full vs truncated-k 作为受控因子。
- 循环位置只有"中间三分之一"，无全栈、无 prelude/coda 比例变化；需要我们补。
- 采样 T 会让每个 run 的 FLOP 成为随机量且分布依赖 μ_bwd；测 φ 时固定 r（iso-depth 做法）更干净；若要研究测试时外推再加采样组。
- 他们不报 CI、不报 Z/z、不说明排除点；我们应补 bootstrap CI。
- 低预算下 looping 劣于 fixed-depth：4×4090 的预算大致对应他们最低的预算档（1e18 ≈ 140M × ∼1.2B tokens），要预期 μ*_rec 很小、信号弱，需要更多预算点与种子。

**(a) 测量条件**：无 φ；训练律指数 a 在 μ_rec ∈ {2,4,6,8,10,12}（Poisson 均值，per-sequence 采样）、**截断反传 μ_bwd = ⌈μ_rec/2⌉**、参数固定 140M / 370M、C ∈ [1e18, 1.28e20] FLOPs 下拟合；无 r = 1 稠密模型进入拟合（μ_rec = 1 只作为前沿对照）。
**(b) 缺的组合**：full BPTT 的 scaling 网格；k 扫描（只有 Appendix I 的 μ_rec = 20 单点）；唯一参数量随 r 变化（iso-FLOP 下不同 N）；全栈循环与不同 prelude/coda 比例；固定 r 训练；与更大稠密模型的 FLOP 匹配对比；训练种子。
**(c) FLOP 公式**：C = (2N̂₁ + 6N̂₂)·D 可以沿用（等价于 iso-depth Eq. 6），但要自行明确 N̂ 是否把 prelude/coda 计一次、是否含 unembedding（他们含）、attention 项怎么算（他们只写 "following Chowdhery et al., Karpathy"，未给公式）；对角注入的参数与 FLOP 为 O(d)，可忽略。
