## 摘要

循环（递归深度）Transformer 把一个由若干层组成的块执行 *r* 次。它要付出这个块 *r* 倍的计算量，但不增加参数。人们对它有两个期望：表现得像一个更大的模型（参数效率）；推理时多跑几圈就能解更难的题，而不必写出思维链（潜空间推理）。我们用同一套配方测量了这两件事：一个预注册的网格，共 111 次训练（10M–80M 的循环模型，作参照的普通模型最大到 160M，较小的尺寸各 3 个种子）；三项延伸实验；一个需要串行步骤的合成任务；以及分两批、在运行前冻结了方案的九项补充实验（S1–S3、S4–S9）。

### 在网页文本上：参数效率和数据效率，不是算力效率

1. **参数相同时约 40M 起循环更好；训练算力相同时普通模型更好。** 参数和 token 数都相同时，中间块循环 4 次的模型在 10M 上比普通模型*差* 0.02–0.10 nats，到 160M 变为*好* 0.03–0.06 nats（每参数 10–40 个 token）；而且优势随每参数训练 token 数的增加而持续扩大：每参数 token 数为 160 时，10M、循环 8 次的模型与用 1.7 倍 token 训练的普通模型持平。训练算力相同时，在普通模型损失为实测值的 258 次比较中普通模型全部胜出，实测范围现已到 10M 的每参数 640 个 token、20M 的 320 个（补充实验 S4）；差距随每参数数据缩小，循环模型最高预算处为 0.01–0.05 nats；用循环模型自己的学习率时，10M、每参数 160 个 token 处两者持平（两个种子 −0.011、+0.005），这是唯一一个不是普通模型赢的同算力比较。40M–160M 上超出实测普通模型曲线的 62 次比较仍依赖外推。在 10M–40M 上为两种模型都重新调学习率（补充实验 S1）后，这三条结果都不变；原来用同一个学习率，如果说有偏差，也是低估了循环模型，在 10M 上约低估 0.02 nats。
2. **预注册的那个数 φ，在绝对值上不可辨识**，因为把损失换算成"等效参数"的普通模型尺子是弱可辨识的：主拟合给出各单元 φ = 0–0.17，联合拟合给出 0–0.41。它的趋势是稳健的：按尺寸分别拟合，φ 从 10M 时的负值升到 160M 时的约 0.65。不用尺子直接测量，中间块循环 4 次的模型每个参数在 10–20M、每参数 10–20 个 token 时相当于 0.6–1.0 个普通模型参数，在 40M–160M、每参数 20–40 个 token 时相当于 1.26–1.46 个（局部 φ 0.35–0.52，接近 Schwethelm 等的 0.46）；已发表的 130M–1.4B 同参数结果换算后也在同样的 1.2–1.6。φ 不是结构的常数。
3. **四个预注册假设没有一个按原来的表述成立。** 截断反传没有降低 φ（它对整栈循环有帮助），中间块循环在原始损失上胜过整栈循环、但在 φ 上并不一致，φ 随 *r* 饱和的形式没有比 r^φ 外推得更好（数据分不出两者），训练算力和部署算力两种口径下算力最优的都是普通模型。
4. **在文本上，循环并不是在迭代逼近答案。** 用固定圈数训练时，它执行一个固定长度的程序，最后一圈是一次幅度很大的"转身"；用截断反传训练时，它学到一个周期性的循环；用随机圈数训练时（与 Huginn 相同），它收缩到一个不动点。三者在推理时多跑圈数都得不到任何收益，不论学习率多少。
### 在需要串行步骤的任务上：推理时可以延长的深度

5. **一圈一步，多给圈数解更长的链，还有不看答案的停法。** 在查找表链上，循环模型一圈推进一步（探针看得到），推理时多给圈数就能解出比训练时更长的链：用 8 圈训练的模型在 12 步题上从 0.04 升到 0.86，收益随长度衰减（到 16 步左右）。普通模型一出训练范围就失败，即使执行深度相同、参数多达 4.4 倍；固定圈数的循环模型按自身圈数也是如此。循环多出来的是一种推理时可以加长的深度。模型自己的置信度是一种不看答案的停法：阈值 0.99 时，它为固定圈数和随机圈数训练的模型拿回 97–98% 的多跑圈收益（S8）。用圈数 = 步数训练的模型外推最远（12.8 步），但按状态停不下来；训练时教它在最后一步之后继续循环，它就能保住中间值、靠置信度在 12 步题上停到 0.93，代价是外推少约一步（S9）。学习率决定这一切能不能学到：在对普通模型最优的学习率下，12 个循环运行里有 10 个没能在同样的步数内学会任务（S2）。
6. **写出来的推理在这里做不到这一点。** 把中间值写成 token 的普通模型把训练范围解得完美（每个种子、每个试过的学习率都是 1.000），推理算力只有循环模型按训练圈数运行时的三分之一，但在每一条更长的链上都只有随机水平，36 层也一样；提示里的表一超过 8 张，链在第一、二个 token 就断，这是对输入长度的泛化失败。停顿 token 没有作用（S5）。训练范围内，token 是得到串行步骤更便宜的办法；范围外，这里只有循环能延长。
### 代价

7. **部署时，循环要付出延迟和显存。** 每个实际执行的层各存一份 KV 缓存时，解码时间和缓存都随实际执行的层数增长。同损失时（两种模型都训练到每参数 40 个 token），中间块循环 4 次的模型在 40M–160M 上少用 14–19% 的权重显存，但 KV 缓存是 2.2–2.3 倍、每 token 解码时间是 2.4–2.5 倍，批 32 时峰值显存约为普通模型的 1.6 倍（补充实验 S3）。多圈之间共用 KV 缓存本可去掉这项成本的大部分，但只对随机圈数的模型零代价，而它们的循环本来就没有收益；固定圈数的模型要赔 0.09–0.17 nats，是它们相对普通模型收益的两到四倍（S6）。

### 底下只有一个问题

再跑一遍这个块，什么时候算测试时算力？当任务需要、并且循环被训练成迭代时，把推理放进架构里是有效的；在普通文本上，任务很少需要它，剩下的是一个随规模和数据增长的参数效率收益，代价是解码时间。三个条件把两种情形分开：有余量（错误来自串行步数不够，而不是不知道）、能延伸（循环可以多跑而不破坏状态）、有停的信号。链任务在为之训练后三条都满足；网页文本在这些规模上一条也没有显现。和写成思维链的推理比（在一个合成任务上）：训练范围内思维链更便宜、也同样完美；范围外只有循环能延长。

## 1. 为什么做这项研究

循环 Transformer 把一个由若干层组成的块重复使用多次：例如 Universal Transformers [1]，以及近来的 Huginn [2]、Ouro [3] 等。人们对它有两个期望。第一是**参数效率**：循环模型应当表现得像一个更大的普通模型；当限制部署的是显存或带宽而不是计算量时，这一点很重要。第二是**潜空间推理**：如果循环是在对一个问题反复迭代，那么测试时多跑几圈就应当能解更难的问题，而不需要写出思维链。

这两种说法都很难从已有文献中核实。各项研究的数据、分词器、训练配方和模型家族都不同；很少报告种子；而真正关心的那个量——多一圈值多少——通常是从单次拟合里读出来的。因此我们用同一套配方训练了一组受控的尺寸阶梯，在训练之前写下假设和分析方法（[预注册](preregistration.md)，2026-09-23 冻结），并记录了之后的每一处改动（[偏离记录](deviation-log.md)）。文本上的结果没有检验第二个期望，于是我们构造了一个需要串行步骤的任务，冻结了它的设计和预测，用同样的方式跑了它。

### 相关工作

**一次循环值多少。** Kaplan 等 [4, 附录 D.2] 已经发现，重复使用参数的循环 Transformer"在参数量相同时稍好，但把重复使用算进去、按 FLOP 比较时稍差"；我们的结果在这两个方向上都与之一致。我们检验的等效参数形式 N_eff = N_once + r^φ·N_rec，以及循环前后各两层不共享的结构，来自 Schwethelm 等 [5]：他们在 FineWeb-Edu 上、最多 8 圈、每个运行一个种子、只计非嵌入参数，估计 φ = 0.46（95% 区间 0.41–0.53）；我们的预注册就是为了能与他们比较而设计的（我们的 N 还计入了输出头）。Parcae [6] 发现在参数和 token 数相同（算力不同）时循环能降低困惑度；Lee 等 [7] 发现按相同 FLOP 比较时，普通循环模型的 scaling 比不循环的差；Chen 等 [8] 发现在单 epoch 训练中，把更深模型的权重绑在一起大约要多付一个固定倍数的算力，而在重复数据上最优圈数随算力增长。在 Ouro [3] 的一个受控附录里，同深度的普通模型在每一次比较中都胜过循环模型；[11] 中单纯的递归在相同算力下也比普通模型差。对循环的混合专家模型，一个有上界的形式外推到 16 圈时比 r^φ 更准 [9]；对普通的循环模型，我们的数据分不出这两种形式（H3）。一个 1.4B 的循环模型训练了 310B token（210B 预训练，即在 16B token 的语料上约 13 遍，再加 100B 中期训练），在全部 12 个基准上胜过参数和数据相同的普通模型，代价是每 token 约 4 倍的训练算力；而推理算力相同的 3.9B 普通模型在每个基准上都领先或持平 [10]。这些研究都没有在多个种子下把模型规模和每参数 token 数分开变化；这正是本研究主要增加的东西（3.3 节）。

**循环算的是什么。** 用随机圈数训练的 Huginn [2]，潜在轨迹会收敛到不动点或轨道。Logan [12] 在一个小型深度递归模型中看到逐 token 收敛到不动点，与我们在随机圈数下看到的一致（第 4 节）；Huang 等 [13] 发现固定深度、完整反传的训练会使多圈之间无法共用 KV 缓存（在我们的 20M 模型上，共用缓存让每个从循环得益的模型损失 0.09–0.17 nats，截断反传也一样；S6）。Saunshi 等 [14] 发现循环模型的收益集中在推理任务上，这可能与我们在数学和代码上更大的收益有关。

**串行推理。** 循环网络多跑几次迭代就能解比训练时更难的题，也会"想过头" [15, 16]；圈数随输入而定的循环 Transformer 能推广到更长的输入 [17]。Kohli 等 [18] 表明，测试时多给圈数，递归深度 Transformer 能外推到更深的事实组合链（训练到 12 跳，可达 14–19 跳），而参数相同或 FLOP 相同的普通 Transformer 做不到。Zhang 等 [19] 发现循环每圈解决的位置数与训练长度除以训练圈数成正比，测试时多给的圈数能救回靠后的位置。我们的合成任务结果与这两项都一致；我们增加的是执行深度相同的普通模型对照、多个种子、对每个中间值的探针、学习率对能否学会任务的影响、不看答案的停法，以及在推理算力对齐下与思维链 [27] 和停顿 token [28] 的比较。

**推理成本。** 不共用缓存时，循环模型的 KV 缓存和解码时间随圈数增长：[20] 中两圈约需两倍的 KV 显存和 1.96 倍的延迟，[21] 中普通循环模型在 2、3、5 圈时每步解码分别慢 2.3、3.4、5.7 倍。在多圈之间共用缓存的方案 [3, 13, 21]，本研究只在训练好的模型上事后共用（S6），没有带着共用缓存训练。

## 2. 实验设置

四个预注册假设：**H1** 截断反传降低 φ（在等 token 和等 FLOP 两种口径下都如此）；**H2** 循环中间块的 φ 高于循环整栈；**H3** φ 随 *r* 饱和；**H4** 按训练算力计，算力最优的 *r* 较小，按部署算力计则更大。

## 3. 循环在文本上值多少

### 3.1 预注册假设的判定

| 假设 | 判定 |
|---|---|
| H1 截断降低 φ | 不支持。中间块 0.00 对 0.13（方向与预测一致，区间重叠）；整栈 0.17 对 0.00（方向相反）。等 FLOP 口径下相同。 |
| H2 中间块 > 整栈 | 依口径而异。φ 的结果不一；在执行深度相当时比较原始损失，24 次比较中 24 次偏向中间块。 |
| H3 随 r 饱和 | 不支持。按预注册的外推检验，饱和形式用 10M–40M 预测 80M 比 r^φ 更准（0.0085 对 0.0096），用 20M–80M 预测 10M 略差（0.0203 对 0.0200）；数据分不出两种形式的高下。 |
| H4 算力最优的 r | 无论按训练算力还是部署算力，最优的都是普通模型（r = 1）。 |

途中有一个意外：**截断反传帮助了整栈循环**。在 20M、每参数 token 数为 10 时，整栈循环 4 次的模型截断时达到 3.646，不截断时为 3.783（三种子均值）；在 10M 上，比普通模型好的循环单元只有 r = 8 的整栈循环。截断还带来了损失尖峰：111 次训练中有 30 次至少出现过一次，几乎都在截断或整栈单元里，另有一次训练崩溃。在一项后续实验中，把学习率减半后尖峰消失了。

### 3.2 为什么 φ 这个数定不下来，以及改测什么

φ 需要一把尺子：即用普通模型拟合出的那条公式，它告诉我们一定数量的参数能换来多低的损失。在我们五个普通模型尺寸上拟合时，尺子的不可约损失落在下界上，参数指数 α = 0.054，远低于常见的 0.3。五个尺寸无法把 E、A 和 α 分别定下来。对全部训练做联合拟合得到 α = 0.267，φ 也更大（0–0.41，而不是 0–0.17）。预注册的 φ 值照原样报告（[结果汇总 §3](results.md)），但下面的结论建立在不需要尺子的量上。作为对照，Schwethelm 等 [5] 用他们自己的尺子得到 φ = 0.46；尺子这样难以确定时，不同研究之间的 φ 绝对值很难直接比较。

<p align="center"><img src="../code/results/figures/fig2_phi_by_rung.png" width="70%"></p>

**不用尺子。** 实测的普通模型本身就可以当尺子：对每个循环模型，在用同样 token 训练的实测普通模型之间插值，就能找出损失相同的普通模型大小 N*（[结果汇总 §5.17](results.md)；探索性）。对中间块循环 4 次的模型，倍数 N*/N 从 10–20M、每参数 10–20 个 token 时的 0.6–1.0，升到 40M–160M 时的 1.15–1.5。规模每翻一倍，它乘以 1.21；每参数 token 数每翻一倍，乘以 1.14（循环 8 次时 1.17）。它在每参数 20 个 token 时约 35M、80 个时约 10M 达到 1，也就是循环模型与同大小的普通模型一样好的位置。在 40M–160M、每参数 20–40 个 token 时，它稳定在 1.26–1.46（循环 4 次时局部 φ 0.35–0.52），接近 Schwethelm 等 [5] 的 φ = 0.46；已发表的 130M–1.4B 同参数结果 [3, 6, 14] 换算后也在同样的 1.2–1.6。所以 φ 不是常数：预注册的每单元一个 φ，是把两段平均在一起——小模型、每参数 token 数少时，一个循环的价值不如它的参数；另一段里每个参数约值 1.4 个参数。价值随每参数 token 数变化是一个"循环 × 数据"的效应；已发表的等效参数规律里它只依赖 r [5, 9]，没有这一项。

### 3.3 价值随规模和数据增长

<p align="center"><img src="../code/results/figures/fig12_scale_middle_r4.png" width="60%"></p>

**规模。** 同一个单元（中间块循环 4 次）与同尺寸、同种子的普通模型比较（图 12）。在每参数 token 数为 40 时，从 10M 到 160M 的损失差依次为 +0.018、−0.025、−0.050、−0.055 和 −0.063 nats（负数 = 循环更好），并且在每个预算上曲线都是单调的。160M 的两个种子相差不到 0.001 nats。固定尺子、换算成 φ（探索性），同一单元依次为 −0.32、0.19、0.39、0.52、0.65。以损失计，增量在缩小（每翻一倍依次为 0.043、0.025、0.005、0.008），而 φ 不能超过 1，所以曲线一定会在某处弯下来；我们还看不到在哪里。

<p align="center"><img src="../code/results/figures/fig11_data_extension.png" width="90%"></p>

**数据。** 把已完成的 10M 和 20M 训练继续训到每参数 token 数 80 和 160（图 11），数据每翻一倍，中间块单元的优势就再增加 0.02–0.03 nats，没有饱和的迹象。如果换算成普通模型要追平循环模型所需的数据量，10M 中间块循环 8 次从每参数 token 数 10 时的 0.85× 升到 160 时的 1.68×（两个种子）；20M 的在 80 时达到 1.65×。整栈循环的方向相同。

### 3.4 同算力：普通模型赢，但赢得越来越少

循环训练比同尺寸、同 token 的普通模型训练花更多算力。把每次循环训练的训练算力换算成普通模型用同样算力能看到的 token 数，再从实测的普通模型曲线上读出普通模型的损失，结果是：凡能实测的比较，普通模型都更好。S4 之前，320 次比较中 221 次是实测，全部是普通模型赢、至少好 0.016 nats；99 次需要普通模型曲线之外的损失。两种外推把真值夹在中间：按最后一段实测的斜率外推偏向普通模型（在实测曲线上检验，外推一次翻倍会把损失估低 0.02–0.08 nats，每参数 40–160 个 token 处），对每条曲线拟合幂律则偏向循环（把普通模型损失高估 0.006–0.027 nats，每外推一个翻倍）。用幂律时，99 次里有 6 次是循环更好，最多好 0.021 nats，全在每参数数据最多的地方（[结果汇总 §5.17](results.md)）。补充实验 S4 随后把 10M 普通模型续训到每参数 640 个 token、20M 续到 320 个，320 次比较里 258 次成为实测：普通模型全部胜出，实测的差距落在两种外推大约中间的位置。40M–160M 的 62 次比较仍是外推。

| 循环单元（尺寸，每参数 token 数） | 训练算力，相对同尺寸普通模型 | 同参数同 token 的差 | 同算力的差 |
|---|---|---|---|
| 中间块 r = 4（10M，160N） | 2.2 倍 | −0.034 | +0.016 |

主考卷上循环损失减普通模型损失，种子 42、43 的均值；负数 = 循环更好。同算力时普通模型训练的 token 数是循环模型的 2.2–3.8 倍（[结果汇总 §5.18](results.md)，S4）。

差距随每参数数据缩小：10M 中间块循环 4 次在 40N 时 +0.119、80N 时 +0.062、160N 时 +0.016；20M 从 20N 到 80N 依次为 +0.138、+0.075、+0.022。用循环模型自己的学习率（S1 找到的普通模型学习率的 0.35 倍）时，10M 中间块 r = 4 在每参数 160 个 token 处持平（两个种子 −0.011、+0.005），这是本研究第一个不是普通模型赢的同算力比较；每参数数据再多时它会不会变成循环赢，没有测。在测过的范围内，循环是用算力换参数和数据的办法，不是省算力的办法。

### 3.5 学习率

所有循环语言模型都沿用了普通模型的学习率，因为预注册的检查（20M、每参数 token 数 10）没有找到更好的。补充实验 S1 在 10M、20M 和 40M 上、在上面用到的每个预算下，为普通模型和中间块循环 4 次的模型都重新调了学习率（普通模型学习率的 0.5–1.41 倍，事先定好的边界规则要求时再加 0.35 倍），用一个种子（20M 用两个），所以它的差距与 3.3 节的三种子均值略有出入。普通模型的最优学习率一直是 1×（40M 时 0.71× 在每参数 token 数 40 时好 0.001 nats、在 80 时好 0.004）。对循环模型，同一学习率在 20M–40M 上最多损失 0.006 nats，但在 10M 上，从每参数 token 数 20 起它偏好 0.5× 及更低，差别约 0.02 nats。两边各用最优学习率时，每参数 token 数 40 的差距从 10M 到 40M 依次为 −0.005、−0.031 和 −0.055 nats（同一学习率、同样种子时为 +0.015、−0.031、−0.050）：规模趋势小了一些，但按事先写定的规则仍然成立；10M 的数据趋势更大了（从每参数 token 数 10 时的 +0.082 到 160 时的 −0.059）；同算力的 11 次比较中普通模型仍然全部更好（[结果汇总 §5.16](results.md)）。

### 3.6 收益落在哪里，种子量的是什么

<p align="center"><img src="../code/results/figures/fig5_gap_by_exam.png" width="80%"></p>

逐 token 看，网页文本上的收益是一个幅度小、范围广的整体下移：大约一半的 token 变好；收益集中在难 token 上的程度，不超过两个普通模型种子之间本来就有的差异。在数学和代码上，收益更大（平均约 3 倍和 7 倍；各单元分别为 1.5–7 倍和 4–11 倍），但这两类考卷上种子之间的噪声也大 10–100 倍（图 5）。补充实验 S7 查出了这种噪声的来源：数据顺序。在 20M 上，同一个初始化从数据流的三个互不重叠的位置开始训练，主考卷损失只变动 0.003–0.011 nats，是初始化种子之间差距的 0.1–0.5 倍，所以本报告里的种子区间不需要加说明。在代码考卷上，数据顺序让损失变动 0.21–0.69 nats，最多是初始化差距的 7 倍，循环减普通模型的配对差在不同顺序下会变号。在这个规模上，一次训练碰巧看到哪些文档决定了它的分布外损失，所以分布外考卷在这里不能用来做精细比较（[结果汇总 §5.18](results.md)，S7）。

## 4. 循环块在文本上算的是什么

我们对训练好的模型逐圈做探针：在每一圈之后读取状态，分别用模型自己的输出层直接读（"原样读"，即 logit lens）、在输出层前面加一个训练过的线性变换再读，以及用一个训练过的线性头读。

<p align="center"><img src="../code/results/figures/fig8_loop_probes.png" width="95%"></p>

- **固定圈数（r = 8）。** 加上训练过的线性变换后，第 4 圈之后的状态读出的损失已经与最终损失相差在 0.1–0.2 nats 以内，第 5–7 圈几乎没有再增加什么。最后一圈是一次幅度很大的非线性移动，把状态改写成输出层所期望的形式；37–44% 的 token 的预测直到这一圈才定型。推理时少跑或多跑圈数都会破坏模型（图 6）。这在 20M 和 40M 的不同种子上都复现了。
- **截断反传（整栈，k = 4）** 学到的是周期为 4 的循环：状态每 4 圈回到几乎同一个点，所以模型在 4、8、12 或 16 圈时都能工作，再多跑也没有任何收益。
- **训练时用随机圈数**（每一步从 1–8 中抽取 r，与 Huginn 相同）学到的是向不动点的收缩：推理圈数从 1 到 32，损失在约 4 圈之后都是平的（图 10）。模型对圈数鲁棒，但在标称的 8 圈上比固定 r 训练差 0.05 nats，与普通模型打平。
- **学习率。** 学习率越低，损失随推理圈数变化的曲线越平。这最先出现在预注册学习率检查的 20M 模型上，S1 在 10M、20M 和 40M 上（中间块循环 4 次，每参数 token 数 32 时的存档）证实了它：在 4–16 圈之间，学习率为普通模型 0.5 倍时损失的变化幅度是 0.36–0.77 nats，1.41 倍时是 3.4–4.6 nats。学习率越低，迭代越接近收敛；但在文本上，不论学习率多少，多于训练圈数的循环从来没有带来好处。

## 5. 循环能学会逐步推理吗？

### 5.1 任务和条件

文本很少给循环迭代的理由：预测下一个词很少需要许多串行步骤。因此我们构造了一个需要串行步骤的任务（[设计](synthetic-reasoning-design.md)，2026-10-09 冻结）。每道题给出一个起始值和一串查表操作，例如 `25 ; LUT 7 ; LUT 3 ; LUT 19 ; … =>`，其中每个 LUT 是 32 个定义在 0–96 上的固定随机函数之一；模型必须在一次前向计算中输出最终值。两次查表复合起来是 1024 种任意函数之一，所以处理长链的唯一办法是一步一步地算。模型在 1–8 步的题上训练，测试到 24 步。题目在训练时随机生成，所以短题会重复出现（一步题只有 3,104 种），但超过 8 步的链在训练中从未出现。我们把 8、20 和 36 层的普通模型与一个 8 层的循环模型（执行 2 + 4×r + 2 层）比较，循环模型分别用 r = 2、4 或 8 圈训练，或用随机圈数训练，或用与链的步数一样多的圈数训练。每个条件都使用只按分布内准确率扫描选出的学习率，各有 5 个种子。另有两个条件在 S5 里加入（5.6 节）：把中间值写成思维链的普通模型，以及带停顿 token 的普通模型；还有一种循环训练方式在 S9 里加入（5.5 节）：圈数 = 步数再随机多跑几圈。

### 5.3 循环买到的是步数；普通模型缺的是"多跑几圈"这个选项

参数相同时，圈数越多，能解的链越长（4.2 → 6.4 → 8.0 → 9.0 步）。执行深度相同的普通模型参数是循环模型的 2.4–4.4 倍，少解 1–1.6 步（20 层的那个没有完全学会训练范围），而且一出训练范围就失败：12 步时只有 0.02–0.06。固定圈数的循环模型按自身圈数也是这样（0.03–0.05）。多给圈数后，它们达到 0.64–0.86，随机圈数模型 0.83，圈数 = 步数的模型 0.96。

<p align="center"><img src="../code/results/figures/fig14_synthetic_inference_loops.png" width="95%"></p>

**推理时多跑圈数能解更长的链**（图 14）。用 8 圈训练的模型在 8 圈时能解 9 步，在 16 或 32 圈时能解约 11 步。这个收益是真实的，但有上限：在 16 步时为 0.37。用随机圈数训练的模型同样有收益：16 步时，准确率从 8 圈的 0.08 升到 16 圈的 0.49。用圈数 = 步数训练的模型，跑与链的步数一样多的圈数时，在 10 到 16 步的每个长度上都比 8 圈好 0.34–0.95（种子平均），这正是预先写定的预测 P3(c) 的要求。

### 5.4 每圈算一步

<p align="center"><img src="../code/results/figures/fig15_synthetic_probes.png" width="95%"></p>

在每一圈之后，我们针对每个中间值 x_j，在输入中属于它自己的位置上训练一个线性探针（图 15）。在用 8 圈训练的模型中，x_j 大约在第 j 圈出现（x_8 在第 8 圈；5 个种子都是每步 1.0–1.1 圈），而且每个值之后一直可以解码（保持度 0.96）。用圈数 = 步数训练的模型也是每圈算一步，并且在跑自己的 d 圈期间保持住这些值（0.92），但跑得更久就会丢掉它们，所以它需要差不多 d 圈：它在训练时从来没有在最后一步之后继续循环，而固定圈数的模型有过。用较少圈数训练的模型把更多的步塞进每一圈（r = 4 时每圈约 1.6 步，r = 2 时约 2.4 步），刚好够覆盖训练范围。普通模型算得晚，36 层中大约从第 21 层开始；而且在几个种子中，中间值根本没有出现在各步的位置上。

### 5.5 知道何时停

多跑圈数只有在模型能判断该跑几圈时才有用。我们在同一批存档上试了三种不看答案的停法。

- **冻结设计里的状态规则**：答案位置的状态在相邻两圈之间变化不到 2% 就停，最多 32 圈。每次运行都算了，但直到 2026-10-15 才报告（[结果汇总 §5.15](results.md)）。对用 4 圈和 8 圈训练的模型，它在 12 步上拿回"事后最好"固定圈数收益的约 80%，在 16 步上拿回 60%–70%，平均跑 11–19 圈，而且不影响训练范围。用圈数 = 步数训练、外推最远的模型靠它停不下来：跑过 d 圈后状态一直在变，所以在任何长度上都停在错的圈数（准确率 0.03–0.08）；它外推最远，只是因为题目里写着步数。
- **其他不看答案的规则（S8）**：在同样的 25 个存档上比较，规则和阈值在方案里定好，在一套题上选、在另一套题上报。模型自己的置信度（最高概率到 0.99 就停）最好：对用 4 圈、8 圈或随机圈数训练的模型拿回最好固定圈数在 12 步收益的 97–98%，范围内用的圈数还少于训练圈数；它也把圈数 = 步数的模型拉到 0.76，代价是范围内损失 6–7% 的题。"预测不再变化就停"会在稳定的错误答案上提前触发（固定圈数模型的读出要到最后一圈才转身）；对多圈预测做多数投票能追平最好的固定圈数，但从不超过它，而且不是停法。
- **兼得两者的训练方式（S9）**：把圈数 = 步数的模型改为在最后一步之后再随机多跑 0–4 圈来训练，它保住了中间值（保持度 0.04 → 0.91），外推少约一步（90% 线 11.6 对 12.8），靠置信度在 12 步题上停到 0.93，范围内保住 0.998，用的圈数少于 d。按状态规则，它能不能停因种子而异（0.52；两个种子行，两个不行），所以按方案自己的判读只能说"能保持但没有可用的停法"。训练它每步的算力约为 1.4 倍。

| 模型 | 自身圈数 | 最好的固定圈数（看答案选） | 状态变化 < 2% | 置信度 ≥ 0.99（平均圈数） |
|---|---|---|---|---|
| 循环 r = 2 | 0.05 | 0.62 | 0.45 | 0.70（8.3） |
| 循环 r = 4 | 0.04 | 0.83 | 0.65 | 0.81（9.2） |
| 循环 r = 8 | 0.04 | 0.86 | 0.71 | 0.84（17） |
| 随机圈数 | 0.77 | 0.83 | 0.73 | 0.83（14） |
| 圈数 = 步数（自身 = d 圈） | 0.96 | 0.96 | 0.03 | 0.76（14），并损失范围内 6–7% |
| 圈数 = 步数再多跑 0–4 圈（S9） | 0.90 | 0.94 | 0.52 | 0.93（14），范围内保住 0.998 |

12 步链上的准确率，S8 报告集上的种子均值（[结果汇总 §5.18](results.md)，S8 和 S9）。外推得远和会停来自不同的训练方式；兼得两者的方式是存在的，代价是外推少一点。

### 5.6 循环对写出来的推理

同一个链任务也交给了把中间值写成 token 的普通模型（8 层，与循环模型同参数；36 层，与之同执行深度）和带 d 个停顿 token [28] 的 8 层模型，各 5 个种子，学习率的选法与其他条件相同（补充实验 S5，[结果汇总 §5.18](results.md)）。

| 模型 | 参数量 | 范围内（1–8 步） | 12 步 | 16 步 | 每道 12 步题的层次数 |
|---|---|---|---|---|---|
| 普通 8 层，写思维链 | 6.5M | 1.000 | 0.014 | 0.015 | 416 |
| 普通 36 层，写思维链 | 29.0M | 1.000 | 0.017 | 0.013 | 1872 |
| 普通 8 层，d 个停顿 token | 6.5M | 0.566（解 4 步） | 0.015 | 0.012 | 416 |
| 普通 8 层，只答最终值 | 6.5M | 0.62（解 4.2 步） | 0.064 | 0.048 | 320 |
| 循环 r = 8，8 圈 / 多给圈数 | 6.6M | 0.998 | 0.036 / 0.860 | 0.033 / 0.369 | 1440 / 2720 |
| 循环，圈数 = 步数，跑 d 圈 | 6.6M | 1.000 | 0.957 | 0.366 | 2080 |

种子均值；推理算力按处理的 token 上的层次数计（12 步题的提示有 40 个 token；思维链模型带 KV 缓存再生成 12 个）。

训练范围内思维链是完美的（每个种子、每个试过的学习率都是 1.000），而只答最终值的 8 层模型只解 4 步；12 步时它的推理算力只有循环模型按训练圈数运行时的三分之一（416 次层通过对 1440；真正解出 12 步链的 16 圈要 2720）。范围外它完全不能延长：12 步时 8 层 0.014、36 层 0.017，是随机水平，而循环模型在同样的长提示上为 0.86–0.96。一个诊断显示，提示里的表一超过 8 张，链在第一、二个 token 就断，给定正确前文也一样：这是对输入长度的泛化失败，即 Transformer 在比训练更长的输入上的已知弱点 [31, 32]，不是沿链累积的错误。这个任务的提示随步数变长，所以这个比较说不了输入长度不变的任务上思维链能否延长；针对长度泛化的补救不在方案之内。停顿 token 没有作用（解 4 步，和不加一样）。所以在这个任务上，"花在圈上还是 token 上"有两个答案：和训练题一样长的题，花在 token 上，更便宜也完美；更长的题，花在圈上，它是这里唯一能延长的额外计算。

### 5.7 学习率决定循环能不能学会这个任务

上面所有循环模型都是用 1.25e-4–2.5e-4 的学习率训练的，比为普通模型选出的学习率（5e-4–1e-3）低 2–8 倍。在学习率扫描中（种子 1），同样的 r = 8 结构在 1e-3 下只在恰好 8 圈时工作，没有逐步推进的前沿，和第 4 节的语言模型一样；但它在训练范围内也学得差得多（同样 16000 步后准确率 0.54，2.5e-4 时为 0.999）。对扫描的全部存档做探针，看到同样的分化：对循环 r = 8，学习率不超过 5e-4 时有逐步推进的前沿（1.25e-4 和 2.5e-4 时大约每圈一步，5e-4 时约 1.5 圈一步），1e-3 和 2e-3 时没有；循环 r = 4 和随机圈数模型的表现相同。补充实验 S2 随后把能外推的四个循环条件（r = 2 没有纳入，因为第一版分析漏看了它的外推）在 5e-4 和 1e-3 下用 3 个种子完整训练 32000 步。1e-3 下 12 个运行里仍有 10 个没学会训练范围（准确率 0.49–0.98）。5e-4 下 12 个里有 8 个学会了，它们大多和正式运行外推得差不多远（循环 r = 8：超出训练范围 2.7 步，正式运行 3.2 步；圈数 = 步数：4.0 对 4.8）；例外是随机圈数，学会的两个种子外推 2 步，正式运行 4.2 步。所以学习率高主要是让循环模型在给定步数内学不会这个任务；一旦学会，它学到的大多是同一种可以延伸的算法（[结果汇总 §5.16](results.md)）。

### 5.8 对照预先写定的预测

冻结的设计写了五条预测（[结果汇总 §5.15](results.md)）。P1（参数相同时，圈数越多，能解的步数越多）方向成立，但 r = 8 没有达到 16 步。P2（同深度普通模型至少一样好）按原表述不成立，但差距不大（1–1.6 步，r = 8 时在 P2 允许的范围内）。P3（推理时扩展）前两部分不成立，方向对循环有利：固定 r 的模型*没有*因为多跑圈数而变差，预测不会受益的随机圈数模型在长链上受益了；第三部分成立（圈数 = 步数的模型外推到 16 步；2026-10-15 更正）。P4（只有圈数 = 步数的模型探针表是对角的）对了一半：固定 r 的模型也是。P5（差距比文本上大得多）成立。补充实验的预测：S5 三条成立一条，S8 五条成立一条，S9 四条成立三条；判读见[结果汇总 §5.18](results.md)。

## 6. 循环在部署时的代价

参数相同时，中间块循环 2、4、8 圈每 token 的训练 FLOP 分别是同尺寸普通模型的 1.4–1.5 倍、2.2–2.4 倍、3.7–4.1 倍，每 token 的解码时间分别是 1.5 倍、2.4–2.6 倍、4.5–4.6 倍（一张 RTX 4090，bf16，带 KV 缓存的解码，每个实际执行的层各存一份缓存，即训练时的计算方式；补充实验 S3，[结果汇总 §5.16](results.md)）。更公平的比较是同损失：和在每参数 40 个 token 时达到同样损失的普通模型比（在普通模型尺寸之间插值）：

| 单元 | 尺寸 | 权重显存 | 每 token 的 KV 缓存 | 解码时间，批 1 | 峰值显存，批 1 | 峰值显存，批 32 |
|---|---|---|---|---|---|---|
| 中间块 r = 2 | 20M–80M | 0.93–1.03× | 1.43–1.51× | 1.45–1.49× | 0.99–1.15× | 1.21–1.24× |
| 中间块 r = 4 | 20M–160M | 0.81*–0.96× | 2.20–2.41× | 2.37–2.47× | 0.98*–1.20× | 1.57–1.58× |
| 中间块 r = 8 | 20M–80M | 0.83–0.92× | 4.01–4.23× | 4.27–4.56× | 1.08–1.34× | 2.29–2.40× |
| 整栈 r = 4 | 20M–80M | 1.03–1.11× | 4.02–4.27× | 4.00–4.11× | 1.18–1.84× | 2.32–2.41× |
| 整栈 r = 8 | 20M–80M | 0.81–0.85× | 6.96–7.23× | 7.57–7.91× | 1.27–1.50× | 3.38–3.91× |

循环模型相对同损失普通模型的倍数；\* 160M 超出了最大的普通模型（外推）。

同损失时，循环模型最多省 19% 的权重显存（中间块 r = 4：从 20M 到 160M 依次为 4%、14%、17%、19%），而解码时间和 KV 缓存大致按多执行的层数成倍付出。批 1 时，更大的 KV 缓存几乎抵消了权重上省下的全部（80M–160M：峰值显存低 1–2%）；序列一多，KV 缓存就让循环模型需要更多显存（批 32、1k 上下文时为 1.2–3.9 倍）。所以在这个范围内，循环省的是参数，不是延迟或显存；只有权重主导显存时省得才多，比如更大的模型、一次一条序列、短上下文，这我们没有测。

**在多圈之间共用 KV 缓存**本可去掉这项成本的大部分：每个不同的层只留一份缓存，由该位置最后一圈写入、之后各圈都读它。补充实验 S6 把它用在训练好的 20M 模型上（[结果汇总 §5.18](results.md)）：

| 模型（20M，种子 42，32N 主干） | 推理圈数 | 缓存份数，完整 → 共用 | 完整缓存的损失 | 共用缓存的损失 | Δ |
|---|---|---|---|---|---|
| 中间块 r = 8，不截断 | 8 | 36 → 8 | 3.443 | 3.534 | +0.091 |
| 中间块 r = 8，截断反传 | 8 | 36 → 8 | 3.451 | 3.591 | +0.140 |
| 中间块 r = 8，随机圈数 | 8 | 36 → 8 | 3.496 | 3.496 | 0.000 |
| 中间块 r = 4，不截断 | 4 | 20 → 8 | 3.442 | 3.611 | +0.170 |
| 中间块 r = 4，不截断，学习率减半 | 4 | 20 → 8 | 3.425 | 3.525 | +0.100 |

在这个规模上，每个从循环得益的模型共用缓存后都要赔掉收益的两到四倍（0.09–0.17 nats，对比相对普通模型 0.03–0.05 的收益），所以共用之后会比同尺寸的普通模型还差；截断反传在这里并没有让缓存变得可共用，与 Huang 等 [13] 的发现相反。只有随机圈数训练的模型零代价，它们的循环块收缩到不动点（第 4 节），相对普通模型也没有收益。固定圈数的模型里，学习率低的赔得少（0.100 对 0.170），这指向朝收敛训练、或带着共用缓存训练是得到可共用缓存的路；两者都没有测。

## 7. 实用结论

- **当约束是参数或数据，而不是算力或延迟时，使用循环。** 同参数下的优势随模型大小和每参数 token 数增长（3.3 节）；同算力下我们测过的每一处都是普通模型更好，差距随数据缩小（3.4 节）；部署时循环要按多执行的层数付出解码时间和 KV 缓存（第 6 节）。
- **循环中间块，并且不截断反传。** 在执行深度相当时，中间块循环在每一次比较中都胜过整栈循环。30 个出现过损失尖峰的任务里，25 个用了截断反传（其中 16 个是整栈循环）；在 10M 的补充实验里，把学习率减半就消除了尖峰。
- **在文本上先用 r = 4，并在目标规模上评估。** 在 40M–80M，r = 8 的效果与 r = 4 差不多，但计算量约多 1.7 倍。一次循环在更大的模型、更多的每参数 token 数下更值钱，所以小规模的消融实验会低估它。
- **不要指望在文本上得到测试时扩展。** 固定圈数训练得到的模型只在训练时的圈数下工作；随机圈数训练让模型对圈数鲁棒，但多跑圈数也不会更好（第 4 节）。
- **单独调循环模型的学习率**，小规模和需要逐步计算的任务尤其如此。在文本上，普通模型的学习率在 20M–40M 上与循环模型的最优值很接近，在 10M 上差 0.02 nats；在推理任务上，用普通模型的最优学习率时，多数循环运行在同样的步数内学不会任务（5.7 节）。在推理时扫描圈数，看模型能不能用上更多的圈：在文本上我们的模型都不能；在链任务上，多跑圈数时准确率保持住的模型，也能用这些圈解更长的链。只在训练圈数下工作的模型，在这些圈之内仍可能是逐步计算的（圈数 = 步数的模型就是），探针能把两者分开（5.4 节）。
- **要算上 KV 缓存和延迟，不能只看参数。** 同损失时，循环模型最多省 19% 的权重显存，批 32 时峰值显存是 1.2–3.9 倍；多圈共用缓存要让固定圈数的模型赔掉收益的两到四倍（第 6 节）。
- **在需要串行步骤的任务上，按你需要的长度在循环和思维链之间选。** 训练范围内思维链更便宜也完美；范围外只有循环能延长（5.6 节）。要模型自己停，就用它的置信度：阈值 0.99 拿回了几乎全部多跑圈数的收益；用圈数 = 步数再随机多跑几圈训练，得到的是既能外推又会停的模型（5.5 节）。

## 8. 出了哪些问题，我们改了什么

下面每一项在[偏离记录](deviation-log.md)里都有日期。

- 训练机器的**两次电源故障**（2026-09-24 和 2026-10-07）让 CPU 慢了约 30 倍；训练从存档恢复，没有任何结果受到影响。
- **超参数沿用普通模型的。** 预注册的循环单元学习率检查（20M，普通模型学习率的 0.5–1×，10N）没有找到更好的学习率，但 10 个单元中有 9 个在所试范围的上沿最好，而且检查没有覆盖更长的预算和其他规模。补充实验 S1（[方案](supplementary-experiments.md)，在运行前冻结）在 10M–40M 上、到 40N 为止的每个预算（10M 到 160N），为普通模型和循环模型都重新调了学习率：规模、数据和算力三条结果都成立；同一学习率在 10M 上让循环模型的优势显得小了最多 0.024 nats（20M–40M 上最多 0.005）。在合成任务上，循环模型的最佳学习率比普通模型的低 2–8 倍（种子 1 的扫描）。
- **合成任务在正式运行之前改了两次。** 模运算链在各种长度平均混合的数据上学不会（于是加了课程式喂题），之后仍然学得很慢，所以把运算换成了固定的查找表。两次改动都发生在任何条件之间的比较之前。
- **学习率的选择标准饱和了。** 有几个循环条件在两三个学习率下的分布内成绩都约为 0.999；平局时按实现取了最低的学习率，而协议没有规定这一点，后来发现外推对这个选择很敏感。S5 的思维链条件又一次饱和（每个学习率都是 1.000）。
- **去掉了指针追踪对照。** 它从未做过预试；在按链任务校准的配方下，没有任何条件连单跳都学会。
- **第一版探针每步只读一个位置**，漏掉了某个种子存放在别处的中间值；现在每步读三个位置，取最好的一个。
- **结果首次发布后，一份外部审阅指出了五处错误（2026-10-14 更正）。** (1) "随机圈数模型多跑圈数没有收益"的判定，用的是能解的最长链，而不是设计里写定的准确率之差；按后者它有收益（16 步：0.08 → 0.49）。(2) S3 里批 1 的峰值显存多算了一份 KV 缓存，已重测。(3) H3 用的 AIC 是由 Huber 损失算出的代用分数，不是基于似然的 AIC，不再当作证据引用。(4) H3 的外推检验把 160M 一档留在了训练集里，和预注册的划分不同；按预注册重做后，r^φ 不再在两个方向上都更好。(5) 设计文档说合成题目不会重复，短题其实会重复。第六处是重跑已完成的运行可能覆盖它的配置记录，这没有影响任何已发布的运行（219 份记录和结果全部一致），训练程序现在会拒绝这种重跑。
- **第二次复核（2026-10-15）又发现了一些错误，已更正。** 合成任务上：预注册的 P3(c) 按它自己的判断依据其实成立（之前判为部分成立，是因为加了设计里没有的要求：每个种子都在 90% 线上解出 16 步）；P4 用了设计里没有写的指标来判定（按对角线占比判定，结论相同）；"圈数 = 步数的模型会覆盖算出的值"是错的（在自己的 d 圈内它保持住了）；与普通模型的 12 步比较混进了多给的圈数；"多给圈数后的最好值"漏掉了 r = 2 的 4 圈和 8 圈。文本上：等算力比较现在写明 320 次里有 99 次依赖偏向普通模型的外推（S4 之后为 62 次）；另外改了约 20 处数字和措辞，包括联合拟合的 φ（0–0.41）、"φ 在每一档内都随 r 递减"（只在 80M），以及训练日志在仓库里的说法（日志已于 2026-10-15 补上）。细节见偏离记录。
- **设计预先写定的一项评测算了却没有报告**，直到 2026-10-15：圈数 = 步数条件的自动停。现在写进了 5.5 节和[结果汇总 §5.15](results.md)，其余条件的同样停法一并报告（探索性）。
- **S5/S9 的两种合成条件显存不足**（2026-10-16）：最深的两种条件在方案冻结前只在 CPU 上测过，按设计的批量放不进 24 GB 的显卡；改为一批拆两半累积梯度（损失和更新不变）重跑，比计划晚了七小时。训练程序现在会记录峰值显存。
- **一个未解释的异常：** 在 160M、每参数 token 数为 40 时，一个循环模型种子在分布外考卷上比另一个差 0.2–0.6 nats，而两者在主考卷上的损失相同。

## 9. 局限

- 规模：10M–160M 参数、16k 词表，远小于部署循环语言模型时的 1B+ 规模。scaling 趋势可能会弯折；我们有五个尺寸，80M 只有一个种子，160M 只有一个循环单元。
- 一个数据来源（FineWeb-Edu），单 epoch；没有覆盖多 epoch 的情形，而循环在那里可能更重要 [8, 30]。
- 部署成本只在一种 GPU 上、对最大 160M 参数的模型测过，并且每个实际执行的层各存一份 KV 缓存；权重主导显存的更大模型没有测，多圈之间共用缓存只在训练好的模型上事后测过（S6）。
- 学习率只为 10M–40M 上的一个循环单元重新调过（S1），一个种子（20M 两个）；其余单元以及 80M、160M 用的都是普通模型的学习率。
- 合成任务的证据来自一个任务族和 6.6M 参数的模型；外推长度在种子之间差别很大。
- 与写出来的推理的比较（S5：思维链 [27] 和停顿 token [28]）只覆盖一个合成任务、6.5M–29M 参数的模型和一种训练制度。这个任务的提示随步数变长（3d + 4 个 token），所以思维链模型在训练范围外的失败是对更长输入的泛化失败，而循环模型在同样的提示上能解；输入长度不随步数变的任务上思维链能否延长，没有测。思维链模型没有得到任何长度泛化方面的帮助，连续思维 [29] 没有试。
- 种子只改变初始化，S7 除外：它在 20M 上改变了数据顺序，分布内其影响小于初始化，分布外大于初始化。
- 40M–160M 上超出测过的普通模型曲线的等算力比较（320 次中的 62 次）依赖外推（3.4 节）；10M–20M 的普通模型曲线现在到每参数 640 和 320 个 token（S4）。
- 四项后续实验考虑过但没有做（作者 2026-10-17 的决定）：输入长度固定的第二个合成任务族、文本上执行深度相同的普通模型对照、80M 再加两个种子、在推理为主的文本上训练普通模型和循环模型。每一项都对应上面的一条局限（[路线图](roadmap.md)、[论文计划](paper-plan.md)）。
